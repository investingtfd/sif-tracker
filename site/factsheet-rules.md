# Factsheet-only rules (extra to the routine prompt; where they differ, this file wins)

The daily routine reads this file in Step 0 and applies it in every run.

L13. Ashish decided on 5 Nov 2026: a factsheet-only fund must never show older position-level numbers as if they were current. The page supports this from data alone; never edit WordPress. A factsheet-only update that writes only size and top holdings is incomplete: apply Step 3h (key details, performance, strategy_overview, debt quality) and the rules below in the same pass, and sweep every entry with factsheet_only = true idempotently.

Step 3h tweaks: scheme_details fund_managers role may be "Fund manager" when the AMC does not split equity and debt. Omit ber_regular_pct and nav_regular when the factsheet gives only links. strategy_overview buckets: name = AMC bucket name, group = AMC's own grouping (quant: "<range> of the fund"), match = exact split labels; never let two buckets match the same split line (quant: only the cash equity bucket matches Equity / Equity (unhedged) and Arbitrage (hedged equity); one debt or margins bucket matches Fixed income).

Step 3i. Factsheet-only display rules.
(1) Unhedged card: set unhedged_pending = true and, when the factsheet states the month's average exposures, unhedged_factsheet = {as_on, long_pct, short_pct, net_pct, deployment_pct, beta, text}; text = "<AMC> publishes the position-level file every two months, so we do not show last month’s positions as if they were current. The <Month> factsheet gives the average: unhedged long about L%, short about S%, net about N% of the fund, portfolio beta B." If no averages are stated, set unhedged_pending only, keep old unhedged fields, and list the fund under Fails and fixes as "no factsheet exposure figures".
(2) Exposure card: exposure = {items: [["Average unhedged long exposure", L, "eq"], ["Average short exposure", -S, "sh"] (only if S > 0)], net: N, note: "<Month> average from the AMC factsheet: equity deployed about D% (long plus short), beta B. Month-end positions follow when the full portfolio is published."}.
(3) stale_sections = {unhedged: "<DD Mon YYYY of last workbook>", sectors: "<same>"}. Do not change holdings_count, derivative_gross_exposure_cr, turnover_ratio, sectors or the asset split from the factsheet.
(4) When the workbook for that month or later is loaded, remove factsheet_only, unhedged_pending (unless TU.finalize sets it), unhedged_factsheet, stale_sections and the factsheet exposure.
(5) Risk band: re-read from the factsheet gauge every month (Step 3b).
(6) quant recipe (SIF-3 Long-Short, SIF-7 Hybrid, SIF-25 Ex-Top 100, SIF-93 Active Asset Allocator, SIF-117 Sector Rotation): open https://www.qsif.com/downloads/factsheet in the browser pane, wait 2.5 s, add script tags in this order: https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js then .../pdf.min.js, set pdfjsLib.GlobalWorkerOptions.workerSrc='data:text/javascript,', fetch the newest "Factsheet <Month Year>" PDF (named after the publish month; the November file holds 31 October data) and read all page text. Each fund has three pages (0-based first page: Ex Top 100 = 12, Active Asset Allocator = 16, Long Short = 20, Hybrid = 24, Sector Rotation = 28; verify by name). Page 1: positioning, strategy ranges (become strategy_overview buckets). Page 2: performance table and key details (scheme_details). Page 3: fund size, inception, managers, monthly commentary with the average exposures (and for Hybrid and Active Asset Allocator YTM, durations, maturity, rating mix) and TOP 10 UNHEDGED POSITIONS. Equity rows go to top_equity (InvITs flagged InvIT); Debt, T-bill, CP, CD and ETCD rows are left out of top_equity. Title-case names, keep ITC, LG, ESDS, IRB, LIC, ICICI upper case. Risk band is a picture: render the page to canvas at scale about 7, find RISK BAND via getTextContent, crop the gauge just below it, screenshot and read RISK-LEVEL n. Sanity: size within 0.5x-2x of previous.

Step 4/5 additions: after committing, open the live tracker and confirm each factsheet-only fund shows its caveat and the average-exposure card. Add the report line "Factsheet display check (Step 3i): <funds, and whether each has unhedged_factsheet, exposure and stale_sections>".

L20. Risk bands are read automatically every run, for every fund, from BOTH sources (Ashish, 13 Nov 2026: he cannot do this by hand for 35 funds). This replaces the "only for funds updated in this run" limit of Step 3b and the keep-the-supplied-value rule of Step 3c(3) and L18.
(1) What to read. The fund's own risk band (never the benchmark's) and, when shown, the benchmark's band (benchmark_risk_band), from the newest source for the entry's as_of month: the monthly workbook (a "Risk band" or "Risk-o-meter" cell or note on the Summary or first sheet, where the AMC prints one) and the factsheet or fund note (text such as "Risk band Level N", "RISK LEVEL N", "Risk Level N", or the gauge). Do this for every fund whose factsheet or workbook for as_of is out, whether or not anything else changed.
(2) How to read the factsheet. First the PDF text (pdf.js text content, search /risk[- ]?(band|level)[^0-9]{0,40}([1-5])/i; Altiva prints "Risk band Level N" for the fund and then for the benchmark, HSBC prints "RISK LEVEL N", Kotak prints "Risk Level N" under each gauge; the fund's comes first). If the band is only an image, render the risk page to a canvas (page.render, scale 2), add the canvas to the AMC page, take a screenshot or zoom of it in the browser pane and read the circled level yourself. Only a clearly legible circle counts. Never guess.
(3) Precedence. The factsheet or fund note for the current month wins over the workbook; the workbook wins over the previous month's value; any value Ashish supplied earlier (SIF-154 = 2, SIF-156 = 3, SIF-80 = 1, SIF-161 = 5) is overridden only by a band actually read from a document for a later or equal month, and the change is logged. If workbook and factsheet disagree, write the factsheet value and list the disagreement under Fails and fixes.
(4) Writing. Set risk_band (1-5) and benchmark_risk_band when read, never null over an existing value. If a band cannot be read, keep the previous one and list the fund under "risk band not read" with the Resolution "Will retry automatically next run".
(5) Reporting. Add one line under the AMC table: "Risk-band check (L20): read for N of 35 funds from the factsheet and M from the workbook; changed: <fund old -> new, source>; not read: <funds and why>". Any CHANGED band is also named in the first line of the notification, because it is investor-relevant.
